# Markdown文档审查Skill

## 介绍

Markdown文档审查Skill是一款交互式文档审查工具，专为Committer和Reviewer设计，帮助高效审查GitCode上Pull Request中的Markdown文档变更。仅关注 `.md` 文件内容质量，不审查代码文件。

## 核心功能

- **原型与头文件一致性**: 文档中函数原型、宏定义、常量值、参数名必须与头文件定义完全一致。
- **参数解释准确性**: 每个参数有对应说明，数据类型、约束条件、取值范围、默认值描述准确。
- **代码样例正确性**: 代码示例中无未定义的变量/函数/类，所有引用符号已声明或说明来源。
- **开源写作规范**: 覆盖文件命名、标题、字体样式、图片、代码块、列表、链接、表格、标点等17类规范。
- **评论提交需用户确认**: 审查完成后向用户询问需要提交哪些问题，未经用户确认不会自动提交评论到GitCode PR。
- **行内评论**: 支持将评论关联到具体文档行。
- **结构化报告**: 生成清晰的审查报告，按严重程度分类。

## 支持的审查维度

| 维度 | 严重程度 | 说明 |
|------|---------|------|
| 原型与头文件一致性 | HIGH | 文档中函数原型、宏定义、常量值、参数名必须与头文件定义完全一致 |
| 参数解释准确性 | HIGH | 每个参数有对应说明，数据类型、约束条件、取值范围、默认值描述准确 |
| 代码样例正确性 | HIGH | 代码示例中无未定义的变量/函数/类，所有引用符号已声明或说明来源 |
| 文档写作规范 | MEDIUM | 文件命名、标题层级、字体样式、图片、代码块、列表、注释符号、链接、锚点、表格、标点符号、目录结构、文件编码、产品型号命名、产品标签使用规范、目录文件规范、术语规范性等17类规则 |
| 语言通顺性 | HIGH | 语句通顺、语法正确、无错别字、无歧义表达、中英文混排规范 |

## 适用人群

- **Committer**: 在合并代码前进行文档质量把控
- **Reviewer**: 高效完成Markdown文档审查任务
- **团队**: 提升文档审查质量和效率

## 技术栈

- Python 3.8+
- Python `requests` 库
- GitCode API v5
- OpenCode LLM集成
