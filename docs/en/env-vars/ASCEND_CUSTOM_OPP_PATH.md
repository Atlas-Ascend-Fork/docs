# ASCEND_CUSTOM_OPP_PATH

## Function Description

Runtime search path for user-defined custom operators. After this path is configured, in the scenario where the operator is integrated into a graph, the GE framework searches for and uses operator binary files based on this environment variable during graph compilation and execution. You can configure multiple paths, separated by colons (:).

Supported custom operator compilation methods and path configuration:

- **Custom operator package**: When the operator is compiled into a custom operator package and the package is installed to a specified path using `--install-path=<path>`, run the following command before calling the operator: `source <path>/vendors/<vendor_name>/bin/set_env.bash`. This script adds the operator package directory `<path>/vendors/<vendor_name>` to the beginning of the **ASCEND_CUSTOM_OPP_PATH** environment variable so that the framework can find the custom operator package at runtime.
- **Dynamic library**: When the operator is compiled into a dynamic library, configure the installation path of the dynamic library. In this case, the dynamic library can also be used through dynamic library linking, which has a higher priority than the environment variable configuration method.

When dynamic library compilation and custom operator package compilation are used together, the dynamic library generated by the former has a higher priority.

## Configuration Example

In the following example, `<path1>` and `<path2>` are the operator package installation directories specified by the developer, and the priority of the compilation output is `1>2`.

```bash
export ASCEND_CUSTOM_OPP_PATH=<path1>/vendors/vendor_name1:<path2>/vendors/vendor_name2
```

In the following example, `<path1>` and `<path3>` are the operator package installation directories specified by the developer, and `<path2>` and `<path4>` are the directories where the dynamic library compilation output is stored. The priority of the compilation output is `2>4>1>3`.

```bash
export ASCEND_CUSTOM_OPP_PATH=<path1>/vendors/vendor_name1:<path2>/op_api/lib/:<path3>/vendors/vendor_name3:<path4>/op_api/lib/
```

## Constraints

None

Supported on all chips
