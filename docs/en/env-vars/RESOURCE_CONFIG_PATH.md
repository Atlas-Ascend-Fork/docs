## Function Description

This environment is used to set the storage path of the heterogeneous resource description file.

The heterogeneous resource description file is a JSON file that contains the description information of a single node and a cluster. For the configuration example and field meanings, see "Appendix \> numa_config.json Configuration" in the *DataFlow Development Guide*.

## Configuration Example

```bash
export RESOURCE_CONFIG_PATH=/home/test/numa_config.json
```

## Constraints

None
