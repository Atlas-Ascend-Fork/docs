# Overview

When tuning performance, use the performance tuning tools to collect and analyze key performance metrics of each running phase of AI tasks running on Ascend AI processors. Based on the collected profile data, you can quickly locate software and hardware performance bottlenecks, a way to more efficient AI task performance analysis.

Performance tuning involves many use cases. The following table associates collections tools with use cases and parsing tools for your reference.
