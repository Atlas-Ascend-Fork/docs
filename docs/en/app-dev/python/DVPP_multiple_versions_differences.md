# Differences Between V1 and V2

- Media data processing V2 APIs: These APIs are suitable for computer vision apps. Their input and output data is based on image parameters. Multiple image formats such as YUV420 and RGB are supported, providing richer and more flexible parameter configuration capabilities.
- Media data processing V1 APIs: These are media APIs of an earlier version. They are no longer evolved and are replaced by V2 APIs.
