# Feature Support by Different Product Models

<!-- md-trans-meta sourceCommit=fdf4276c76935b494f8459e5a6e0a3e968866a42 translatedAt=2026-10-23T10:37:16.062Z pushedAt=2026-10-26T03:10:39.434Z nl=2 -->

The support status of each media data processing function on each product model is as follows. √ indicates supported, and ☓ indicates not supported.

    <!-- npu="950" id1 -->
- The following functions are supported on Ascend 950PR&950DT products:
    - Media data processing operator
    - DVPP image/video processing (media data processing V2)

        The support status of each sub-function is as follows: VPC (**√**), JPEGD (**√**), JPEGE (**√**), PNGD (**√**), VDEC (☓), VENC (☓)
    <!-- end id1 -->

    <!-- npu="A3" id2 -->
- The following functions are supported on Atlas A3 products:
    - Media data processing operator
    - DVPP image/video processing (media data processing V2)

        The support status of each sub-function is as follows: VPC (**√**), JPEGD (**√**), JPEGE (**√**), PNGD (**√**), VDEC (**√**), VENC (☓)

    - DVPP image/video processing (media data processing V1)

        The support status of each sub-function is as follows: VPC (**√**), JPEGD (**√**), JPEGE (**√**), PNGD (**√**), VDEC (**√**), VENC (☓)
    <!-- end id2 -->

    <!-- npu="910b" id3 -->
- The following functions are supported on Atlas A2 products:
    - Media data processing operator
    - DVPP image/video processing (media data processing V1)

        The support status of each sub-function is as follows: VPC (**√**), JPEGD (**√**), JPEGE (**√**), PNGD (**√**), VDEC (**√**), VENC (☓)

    - DVPP image/video processing (media data processing V2)

        The support status of each sub-function is as follows: VPC (**√**), JPEGD (**√**), JPEGE (**√**), PNGD (**√**), VDEC (**√**), VENC (☓)
    <!-- end id3 -->

    <!-- npu="310b" id4 -->
- Atlas 200I/500 A2 inference products support the following features:
    - Video data obtaining and processing in camera scenarios
    - Video decoding, processing, and display in NVR scenarios
    - Voice intercom in NVR scenarios
    - Audio capture & audio playback
    - DVPP image/video processing (media data processing V2)

        The support status of each sub-function is as follows: VPC (**√**), JPEGD (**√**), JPEGE (**√**), PNGD (**√**), VDEC (**√**), VENC (**√**)

    - DVPP image/video processing (media data processing V1)

        The support status of each sub-function is as follows: VPC (**√**), JPEGD (**√**), JPEGE (**√**), PNGD (**√**), VDEC (**√**), VENC (**√**)
    <!-- end id4 -->

    <!-- npu="310p" id5 -->

    - DVPP image/video processing (media data processing V2)

        The support status of each sub-function is as follows: VPC (**√**), JPEGD (**√**), JPEGE (**√**), PNGD (**√**), VDEC (**√**), VENC (**√**)

    - DVPP image/video processing (media data processing V1)

        The support status of each sub-function is as follows: VPC (**√**), JPEGD (**√**), JPEGE (**√**), PNGD (**√**), VDEC (**√**), VENC (**√**)
    <!-- end id5 -->
