# Environment Setup

When developing and compiling AI applications based on the APIs provided by CANN, the development environment must meet the following basic software and hardware requirements:

- Hardware: an x86 server or an Arm server.
- Software: install the CANN Toolkit developer suite package and the CANN ops package.

If you need to run the AI application, the runtime environment must also meet the following basic software and hardware requirements:

- Hardware: a product equipped with an Ascend AI processor (usually also called NPU).
- Software: in addition to the CANN Toolkit developer suite package and the CANN ops package, install the NPU firmware package and the NPU driver package.

You can click [here](https://www.hiascend.com/cann/download) and follow the instructions to install the software packages in the environment. For detailed installation instructions, see [CANN Software Installation](https://www.hiascend.com/document/detail/en/CANNCommunityEdition/latest/softwareinst/instg/instg_0000.html?OS=openEuler&InstallType=netyum).
