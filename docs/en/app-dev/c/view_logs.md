# Viewing Logs

Logs are mainly used to record the running process and exception information of the system, helping users quickly locate problems that occur during system running and debug programs during development. Logs are classified as follows:

- **System logs**: logs generated on the device side when the system is running. They mainly include:
    - System logs on the Control CPU, including kernel-mode logs and user-mode logs generated by system processes, which mainly reflect the overall running status of the AI processor.
    - System logs on non-Control CPUs (for example, low-power CPUs), which mainly reflect the running status of components such as low-power, Task Scheduler, and ISP.

- **Application logs**: logs generated when AI applications are running. They mainly include:
    - Logs printed by components such as GE, Runtime, and HCCL on the host side.
    - Logs printed by the AI CPU process on the device side.

For details about how to view logs and set log levels, see [Log Reference](https://gitcode.com/cann/runtime/blob/9.2.0/docs/zh/log_ref/README.md).
