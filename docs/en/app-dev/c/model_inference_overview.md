# Model Inference Overview

In this chapter, a model refers to an OM model generated by compiling a trained open-source framework network model based on the CANN Graph Engine (GE). When compiling a model, GE performs operations such as graph optimization, operator scheduling optimization, and weight data rearrangement to further tune the open-source framework network model, meet the high-performance requirements in deployment scenarios, and ensure efficient running on AI processors.

GE provides the following two model compilation methods:

- Use the Ascend Tensor Compiler (ATC) to compile a trained open-source framework network model into an OM model file. For beginners, using ATC commands is more appropriate. This chapter also uses ATC as an example to describe how to compile a model.
- Use the graph development APIs to convert a trained open-source framework network model into a computation graph (Ascend Graph) represented in Ascend IR (Ascend Intermediate Representation). For details, see [Graph Development](https://gitcode.com/cann/ge/blob/9.2.0/docs/en/user_guides/graph_dev/README.md).

After the OM model is compiled, model inference is implemented based on the model loading and execution APIs provided by GE. The API call process is shown in the following figure:

**Figure 1** API call process  
![](figures/model_inference_API_call_process.png "API call process")

The key APIs are described as follows:

1. Initialization includes calling the **aclInit** API to initialize the system and calling the **aclrtSetDevice** API to specify the compute device.

    When developing an application using ACL APIs, you must call the **aclInit** API for initialization first. Otherwise, subsequent initialization of internal system resources may fail, which may cause other service exceptions.

2. Call the model loading API (for example, **aclmdlLoadFromFile**) to load the OM model. A model ID is returned upon successful loading.
3. Call the model execution API (for example, **aclmdlExecute**) and specify the model ID to perform inference.

    If an asynchronous model execution API (for example, **aclmdlExecuteAsync**) is used, before executing the model, call **aclrtCreateStream** to create a stream. A stream is equivalent to a task queue that ensures tasks are executed in the order in which they enter the queue. After executing the model, call **aclrtSynchronizeStream** to wait until all tasks in the stream are complete. After the stream is no longer used, call **aclrtDestroyStream** to destroy the stream.

4. Call **aclmdlUnload** to unload the model.
5. Deinitialization includes calling **aclrtResetDevice** to release resources on the device and calling **aclFinalize** to release the resources used by the ACL APIs in the process.
