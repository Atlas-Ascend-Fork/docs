# Overview

This chapter collects typical or frequently occurred problems in inference, training, and operator execution processes, and provides symptoms, locating methods, and solutions for these problems.

The log information may be different between the old and new versions due to continuous software optimization. The log snippets in this chapter are for reference only. The YYYY-MM-DD-HH:MM:SS.fff.uuu (year-month-day-hour:minute:second.millisecond.microsecond) in the log example represents the log output time.

For more cases, see  [Fault Case Library](https://www.hiascend.com/document/caselibrary).
