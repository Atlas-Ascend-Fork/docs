# EN0009 Not\_Supported\_File\_Type

## Symptom

The following is error format. The placeholder %s indicates the error cause.

```text
The input PNG picture is not supported. Reason: %s.
```

Error example:

```text
The input PNG picture is not supported. Reason: The input file is not a PNG file. Signature header check failed.
```

## Solution

Please provide the correct file as prompted in the Reason.
