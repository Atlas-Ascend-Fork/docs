# EN0013 Resource\_Error\_Busy

## Symptom

The following is error format. The placeholder %s indicates the error cause.

```text
The channel resources are busy. Reason: %s.
```

Error example:

```text
The channel resources are busy. Reason: Channel 0 of device 0 has been created.
```

## Solution

Please modify the parameter value or adjust code as prompted in the Reason.
