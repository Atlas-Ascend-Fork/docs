# EN0017 Invalid\_Argument\_API\_Call\_Sequence

## Symptom

The following is error format. The meanings of the placeholders %s in sequence are: API name, API name.

```text
Call the following APIs in order: %s and %s.
```

Error example:

```text
Call the following APIs in order: hi_mpi_vdec_start_recv_stream and hi_mpi_vdec_send_stream.
```

## Solution

Please adjust the code as prompted in the error message.
