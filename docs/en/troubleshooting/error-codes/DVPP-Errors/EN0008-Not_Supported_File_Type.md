# EN0008 Not\_Supported\_File\_Type

## Symptom

The following is error format. The placeholder %s indicates the error cause.

```text
The input JPEG picture is not supported. Reason: %s.
```

Error example:

```text
The input JPEG picture is not supported. Reason: Arithmetic codes are not supported. Only Huffman codes are supported.
```

## Solution

Please provide the correct file as prompted in the Reason.
