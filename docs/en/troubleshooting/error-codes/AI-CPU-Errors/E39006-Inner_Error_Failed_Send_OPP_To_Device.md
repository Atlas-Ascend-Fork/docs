# E39006 Inner\_Error\_Failed\_Send\_OPP\_To\_Device

## Symptom

```text
Failed to send the OPP to the device.
```

## Possible Cause

1. The HDC link is faulty.
2. The device status is abnormal.

## Solution

Obtain the host and device logs, and contact technical support at https://www.hiascend.com/support.
