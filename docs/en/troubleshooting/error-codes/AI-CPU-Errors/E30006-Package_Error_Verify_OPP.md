# E30006 Package\_Error\_Verify\_OPP

## Symptom

```text
Failed to verify the OPP.
```

## Possible Cause

1. The AI CPU OPP on the host is tampered with.
2. An ECC memory error occurs on the device.

## Solution

1. Install the correct OPP.
2. Obtain the host and device logs, check whether ECC errors are reported, and contact technical support at https://www.hiascend.com/support.
