# E39011 Inner\_Error\_Failed\_Load\_Package\_To\_Device

## Symptom

The following is error format. The placeholder %s indicates the package name.

```text
Failed to load the package %s on the device.
```

Error example:

```text
Failed to load the package Ascend-aicpu_legacy.tar.gz on the device.
```

## Possible Cause

1. Failed to verify the software package signature on the device.
2. Failed to decompress the software package on the device.
3. Failed to install the software package on the device.

## Solution

Obtain the host and device logs, and contact technical support at https://www.hiascend.com/support.
