# E30003 Not\_Supported\_Specification

## Symptom

```text
The number of started user processes on the device exceeds the limit.
```

## Possible Cause

The number of processes started in the scheduling queue exceeds the limit. For details about the restrictions, see Processes in https://hiascend.com/document/redirect/CannCommercialCppAppendix.

## Solution

Try again 10 seconds after the last training job exits.
