# EO0003 Invalid\_Model

## Symptom

The following is error format. The placeholder %s indicates the error cause.

```text
Invalid model. Reason: %s
```

Error example:

```text
Invalid model. Reason: No layer needs to be quantized in the graph in your configuration.
```

## Solution

Check and rectify the error based on the error message. For details, see the documentation on the official website.
