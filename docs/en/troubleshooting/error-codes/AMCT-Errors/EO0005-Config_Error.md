# EO0005 Config\_Error

## Symptom

The following is error format. The meanings of the placeholders %s in sequence are: configuration file, error cause.

```text
The content of configuration file %s abnormal. Reason: %s
```

Error example:

```text
The content of configuration file CONFIG_FILE abnormal. Reason: The configuration file does not start with { or end with }.
```

## Solution

Check and rectify the error based on the error message. For details, see the documentation on the official website.
