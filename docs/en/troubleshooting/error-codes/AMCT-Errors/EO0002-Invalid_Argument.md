# EO0002 Invalid\_Argument

## Symptom

The following is error format. The placeholder %s indicates the error cause.

```text
Invalid quantization configuration. Reason: %s
```

Error example:

```text
Invalid quantization configuration. Reason: The input parameters do not include parameter INPUT_FORMAT.
```

## Solution

Check and rectify the error based on the error message. For details, see the documentation on the official website.
