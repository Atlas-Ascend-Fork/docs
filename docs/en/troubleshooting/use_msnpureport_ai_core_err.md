# Using the msnpureport Tool to Collect More AI Core Error Information

When locating difficult AI Core errors, in addition to the information collected in  [Collecting AI Core Error Information](collect_ai_core_error_info.md), you also need to use the msnpureport tool to perform some operations to further check operator and hardware issues. The operations include obtaining the device configuration, setting whether the TaskSchedule automatically resets the accelerator, exporting register information, setting the serial or parallel execution of tasks on the AI Core, and masking the task execution on the specified AI Core or Vector Core. After the fault is located, you are advised to restore the configuration to prevent service performance from being affected.

For details about how to use the msnpureport tool and its restrictions, see  Querying and Setting Device Maintenance and Test Configurations  in  [msnpureport Tool](https://support.huawei.com/enterprise/en/ascend-computing/ascend-hdk-pid-252764743?category=reference-guides&subcategory=command-reference). The command in  Querying and Setting Device Maintenance and Test Configurations  is not supported when the application process is running. As a result, the application process may run abnormally or the command in this step may fail to be executed. The command can be used only after the application process exits.
