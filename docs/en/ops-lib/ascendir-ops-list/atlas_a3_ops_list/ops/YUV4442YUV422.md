# YUV4442YUV422

```c
REG_OP(YUV4442YUV422)
    .INPUT(x, TensorType({DT_FLOAT16}))
    .OUTPUT(y, TensorType({DT_UINT8}))
    .OP_END_FACTORY_REG(YUV4442YUV422)
```

## Brief

Converts YUV444 format image to YUV422 format image.

## Inputs

One input, including:
- x: A 3D Tensor with shape (h, w, 4). Must be float16 type. YUV444 input image data.

## Outputs

y: A 3D Tensor with shape (h, w, 2). Must be uint8 type. YUV422 output image data.

## Data Types

Note: The preceding prototypes are applicable to all chips, but the Data Types listed below are applicable only to the current chip.
### AI Core
- input0 x: float16
