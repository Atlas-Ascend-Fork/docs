# InitData

```c
REG_OP(InitData)
    .ATTR(channel_name, String, "")
    .OP_END_FACTORY_REG(InitData)
```

## Brief

Initialize data process channel .

## Attributes

channel_name: A string. Defaults to "" .

## Third-party framework compatibility

Compatible with tensorflow InitData operator.
