# Contribution Guidelines

This project welcomes all developers to explore it and make contributions. Before you start contributing to the community, see [cann-community](https://gitcode.com/cann/community) to learn the code of conduct, sign the Contributor License Agreement (CLA), and understand the contribution process for source code repositories.

Documents that meet the requirements will be published on the [CANN document center](https://www.hiascend.com/en/cann/document).

This project accepts content contributions in Markdown format. You can create documents with the `.md` extension or modify existing documents.

## Contribution Scope

We welcome any contribution that improves document quality, including but not limited to the following:

Error correction and improvement: Fix typos, grammar errors, incorrect code samples, outdated information, or broken links.

Clarification and optimization: Make descriptions clearer and easier to understand, refine sentence structures, and add background information.

Content addition: Add usage samples, API documents, frequently asked questions (FAQs), best practices, or warning notes for existing features.

New content creation: Write brand-new chapters or tutorials for new features, such as operator README files and API introduction documents. If you have any questions, create an issue for discussion first.

Localization: Help us translate or proofread documents in other languages.

Style and navigation: Improve the layout, readability, and navigation structure of the documentation website.

## Writing Requirements

Strictly follow the [document writing specifications](https://gitcode.com/cann/community/blob/master/contributor/docs/document_writing_specs.md).

## Updating/Adding Documents

### Modifying Documents

To update an existing document, click the Edit button in the upper-right corner of the [CANN document center](https://www.hiascend.com/en/cann/document) page to go to the source file. Modify the file and submit a pull request (PR) to contribute.

### Adding Documents

To add a document, create a Markdown file in an appropriate directory. For the directory structure, see [Directory Structure](./README_en.md#directory-structure).

1. Create the file.

2. Edit the directory index file to add the new file to the website.

    Take the environment variable reference as an example. When you add a file, first locate the directory file `README.md` in the `docs/zh/env-vars` directory. This file defines the organization structure of the operator library documentation. Add a link to the new file at the appropriate position.

After you complete the preceding operations, submit a PR to contribute.
